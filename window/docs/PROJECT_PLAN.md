# PROJECT_PLAN.md

## Суть проекта

Проект — сервис для удобного подбора исполнителей по установке и замене стеклопакетов.

Пользователь не хочет долго искать материалы, компании, цены и свободные даты.
Он хочет быстро получить понятный ответ:

- кто может приехать;
- когда может приехать;
- сколько примерно будет стоить;
- будет ли гарантия;
- можно ли доверять компании.

## Какую проблему решаем

Сейчас пользователю сложно:

- найти подходящую компанию;
- понять реальную стоимость;
- сравнить предложения;
- согласовать время;
- понять, кто именно приедет;
- получить гарантию;
- не нарваться на случайную бригаду.

Проект должен сократить этот путь до простой заявки и выбора компании из списка.

## Основной сценарий пользователя

1. Пользователь открывает сайт.
2. Выбирает услугу:
   - замена стеклопакета;
   - установка окна;
   - балконный блок;
   - замер;
   - ремонт/регулировка.
3. Указывает примерные размеры окна.
4. Указывает дату или желаемый временной интервал.
5. Загружает фото окна, если хочет.
6. Видит предварительный диапазон цены.
7. Видит список компаний.
8. Выбирает компанию по цене, рейтингу, гарантии и доступной дате.
9. Оставляет заявку.
10. Компания подтверждает заявку.
11. Пользователь видит статус заявки.
12. После выполнения получает гарантию.

## Важные особенности

### Размеры

Пользователь может не знать точные размеры.
Поэтому нужно разрешить:

- указать примерные размеры;
- выбрать тип окна;
- загрузить фото.

Размеры используются только для предварительной цены.

### Цена

До замера нельзя обещать точную цену.
Нужно показывать диапазон:

Пример:

> Предварительно: 8 000–12 000 ₽  
> Точная цена после замера.

### Дата

Дата пользователя — желаемая.
Компания должна подтвердить дату или предложить другой слот.

### Гарантия

Гарантия — важное отличие сервиса.
После выполнения заказа пользователь должен видеть:

- дату работы;
- компанию;
- срок гарантии;
- описание работ;
- контакты для обращения.

## Карточка компании

В карточке компании показывать:

- название;
- рейтинг;
- количество выполненных заказов;
- примерную цену;
- ближайшую дату;
- срок гарантии;
- район работы;
- фото работ;
- отзывы;
- кнопку выбора.

## Личный кабинет пользователя

Пользователь должен видеть:

- свои заявки;
- статус заявки;
- выбранную компанию;
- дату;
- предварительную цену;
- гарантию после выполнения.

## Личный кабинет компании

Компания должна видеть:

- новые заявки;
- параметры заявки;
- фото окна;
- желаемую дату;
- возможность принять или отклонить заявку;
- возможность предложить другую дату;
- список своих заказов.

## Статусы заявки

Минимальные статусы:

- создана;
- ожидает подтверждения компании;
- подтверждена;
- назначен замер;
- согласована смета;
- в работе;
- выполнена;
- гарантия активна;
- отменена.

## Что оставить на потом

Не делать в первой версии:

- выбор конкретной бригады;
- онлайн-оплату;
- сложный чат;
- мобильное приложение;
- сложный конфигуратор окна;
- интеграцию с картами;
- сложную CRM.
