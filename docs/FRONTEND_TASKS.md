# Frontend task list

Цель: подготовить цельный и понятный визуал ОкнаМаркет для клиентской демонстрации, не расширяя backend-логику MVP.

## Правила визуального прохода

- Не показывать пользователю слова `демо`, `пример`, `заглушка`, `пока не подключено`, `появится позже` и другие служебные формулировки.
- Не выдавать статические показатели, рейтинги, отзывы, даты или гарантии за реальные данные.
- Сохранять текущую архитектуру Laravel + Inertia + React и использовать Wayfinder для маршрутов.
- Не добавлять frontend-зависимости без отдельного согласования.
- Проверять desktop и mobile после каждого законченного блока.
- Каждая видимая кнопка должна выполнять понятное действие; мертвые действия нужно скрывать.
