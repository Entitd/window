# MVP_TASKS.md

## Этап 1. База проекта

Нужно реализовать минимальную структуру сервиса:

- главная страница;
- страница создания заявки;
- страница списка компаний;
- страница карточки компании;
- страница статуса заявки.

## Этап 2. Форма заявки

Форма должна содержать:

- имя пользователя;
- телефон;
- город/район;
- тип услуги;
- примерная ширина окна;
- примерная высота окна;
- желаемая дата;
- комментарий;
- загрузка фото окна, если возможно.

Типы услуг:

- замена стеклопакета;
- установка окна;
- балконный блок;
- замер;
- ремонт/регулировка.

## Этап 3. Предварительная цена

Сделать простой расчет цены.

Примерная логика:

- базовая цена зависит от типа услуги;
- размер окна влияет на цену;
- срочность может увеличивать цену;
- цена показывается диапазоном.

Не нужно делать точный расчет.
Нужно показывать диапазон:

> от X до Y ₽

## Этап 4. Компании

Создать сущность компании.

У компании должны быть поля:

- название;
- описание;
- рейтинг;
- количество заказов;
- минимальная цена;
- срок гарантии;
- район работы;
- ближайшая доступная дата;
- фото работ, если возможно.

## Этап 5. Список компаний

После заполнения заявки пользователь должен видеть список компаний.

В карточке списка показывать:

- название;
- рейтинг;
- примерную цену;
- ближайшую дату;
- гарантию;
- кнопку выбора.

## Этап 6. Заявка

После выбора компании создается заявка.

У заявки должны быть:

- пользователь;
- компания;
- услуга;
- размеры;
- дата;
- комментарий;
- предварительная цена;
- статус.

## Этап 7. Кабинет пользователя

Пользователь должен видеть:

- список своих заявок;
- статус каждой заявки;
- выбранную компанию;
- предварительную цену;
- дату;
- гарантию, если заказ выполнен.

## Этап 8. Кабинет компании

Компания должна видеть:

- входящие заявки;
- параметры заявки;
- возможность принять;
- возможность отклонить;
- возможность изменить статус.

## Этап 9. Гарантия

После выполнения заказа создать гарантийную запись.

Поля гарантии:

- заявка;
- компания;
- дата начала;
- дата окончания;
- описание гарантии.

## Этап 10. Проверка

После реализации проверить:

- пользователь может создать заявку;
- пользователь видит примерную цену;
- пользователь видит компании;
- пользователь выбирает компанию;
- заявка сохраняется;
- компания видит заявку;
- компания меняет статус;
- пользователь видит новый статус;
- после выполнения появляется гарантия.
